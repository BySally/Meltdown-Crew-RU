# Meltdown Crew — русский перевод "Русификатор"

Неофициальная русская локализация **Meltdown Crew**, подготовленная для тестовой версии игры.

В текущей тестовой версии игры русский язык отсутствует. Официальная русская локализация ожидается в полной версии.

## Скачать

**[Русификатор v1.2 (ZIP)](https://github.com/BySally/Meltdown-Crew-RU/releases/download/v1.2/MeltdownCrew_RussianTranslation_v1.2.zip)**

Последние опубликованные версии доступны в разделе [Releases](https://github.com/BySally/Meltdown-Crew-RU/releases).

## Совместимость и установка

Перевод предназначен для тестовой версии игры. После обновлений игры совместимость может измениться. Используйте инструкцию, приложенную к архиву, если она есть, и сохраните резервные копии заменяемых файлов.

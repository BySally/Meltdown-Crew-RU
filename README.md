# Meltdown Crew — русский перевод (тестовая версия)

Небольшой неофициальный сайт для распространения русификатора **Meltdown Crew** на период бета-тестирования. Автор публикации: **BySally**.

**Сайт:** — https://bysally.github.io/Meltdown-Crew-RU/

## Как добавить архив перевода

**Рекомендуемый способ — GitHub Releases:**

1. Открой в репозитории вкладку **Releases → Draft a new release**.
2. Создай тег, например `v1.0-beta`, и название «Meltdown Crew — русский перевод v1.0-beta».
3. Прикрепи ZIP-архив русификатора как **release asset**.
4. Опубликуй релиз. Можно отметить его как **Pre-release** — сайт его тоже найдёт.

Сайт сам найдёт последний опубликованный релиз с ZIP-архивом и активирует кнопку скачивания. Ручное редактирование HTML после публикации релиза **не требуется**. В архив добавь инструкцию по установке и укажи совместимую версию игры.

**Альтернативный способ:** загрузи ZIP с точным названием `Meltdown-Crew-RU.zip` в корень репозитория. После обновления GitHub Pages сайт проверит наличие файла и тоже активирует кнопку. Приоритет отдаётся GitHub Releases.

## Обновления

Для нового перевода создай следующий GitHub Release с новой версией и приложи ZIP. По умолчанию используется самый новый опубликованный релиз, содержащий ZIP-архив.

## Важно

- Это **неофициальная**, независимая от разработчиков локализация.
- Перевод предназначен для **тестовой версии** игры; с обновлениями совместимость может измениться.
- Публикуй только те файлы, на распространение которых у тебя есть права либо разрешение.
- Сам сайт не содержит файлов игры и перевода до их отдельной публикации.

## Содержимое проекта

- `index.html` — весь сайт, включая стили и проверку новых ZIP-архивов.
- `favicon.svg` — иконка сайта.
- `.nojekyll` — выключает Jekyll для статического сайта.
- `README.md` — эта инструкция.

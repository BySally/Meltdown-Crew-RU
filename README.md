# Meltdown Crew — русский перевод (тестовая версия)

Небольшой неофициальный сайт для распространения русификатора **Meltdown Crew** на период бета-тестирования. Автор публикации: **BySally**.

**Скачать:** — (https://github.com/BySally/Meltdown-Crew-RU/releases/download/v1.2/MeltdownCrew_RussianTranslation_v1.2.zip)

## Важно

- Это **неофициальная**, независимая от разработчиков локализация.
- Перевод предназначен для **тестовой версии** игры; с обновлениями совместимость может измениться.
- Публикуй только те файлы, на распространение которых у тебя есть права либо разрешение.
- Сам сайт не содержит файлов игры и перевода до их отдельной публикации.

## Содержимое проекта

- `index.html` — весь сайт, включая стили и проверку новых ZIP-архивов.
- `favicon.svg` — иконка сайта.
- `.nojekyll` — выключает Jekyll для статического сайта.
- `README.md` — эта инструкция.
